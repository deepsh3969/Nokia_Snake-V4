WHAT'S INSIDE

Features

✋

Gesture Control

Steer the snake with hand swipes — pinch for turbo, fist to pause, open palm to restart.

🦴

Real-Time Hand Tracking

MediaPipe detects 21 hand landmarks on every frame at up to 25 Hz with a lightweight ML model.

🎥

Live Camera Feed

A mirrored selfie-style webcam panel with landmarks, detected gesture and tracking status.

⚡

Turbo Mode

Hold a pinch to temporarily boost the snake's speed — release and it returns to a comfortable pace.

🐍

Classic Nokia Gameplay

Grid board, wall and self collision, food spawning, levels that gradually speed up.

🏆

High Score System

Your best run is persisted to disk and shown live in the HUD next to your current score.

  4. ↓
  5. 3MediaPipeDetects 21 landmarks
  6. ↓
  7. 4Gesture DetectionSwipe / pinch / fist / palm
  8. ↓
  9. 5Snake ControlDebounced, no 180° turns

Camera capture and hand tracking run on a background thread, so the 60 FPS game loop never waits for the webcam. If the camera or MediaPipe fails, the game switches to keyboard control automatically.

GET STARTED

Installation

Requires Python 3.11 and a webcam. The game runs locally on your machine.

terminal
# clone the repository
git clone https://github.com/deepsh3969/Nokia_Snake-V4.git
# enter the project folder
cd Nokia_Snake-V4

# create a virtual environment
python -m venv .venv
.venv\Scripts\activate

# install dependencies
python -m pip install -r requirements.txt

# play
python main.py

Keyboard fallback

WASD/Arrows move · Space pause · R restart · Esc quit

Camera issues?

The game shows “Camera unavailable” and keeps playing with the keyboard. Close other apps using the webcam and check your privacy shutter.
