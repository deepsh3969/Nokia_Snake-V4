# 🐍 Nokia Snake — Gesture AI

A modern recreation of the classic Nokia Snake game controlled using real-time hand gestures.

## ✨ Features

- 🐍 Classic Nokia-style Snake
- 👋 Real-time hand gesture control
- 📷 Live webcam feed
- 🤏 Pinch gesture for Turbo Mode
- ✊ Fist gesture for Pause
- ✋ Open Palm to Restart
- 💥 Particle effects
- 🏆 Persistent high score
- 📈 Progressive difficulty
- 🎮 Keyboard fallback controls

## 🧠 Gesture Controls

| Gesture | Action |
|---|---|
| 👋 Swipe Left | Move Left |
| 👋 Swipe Right | Move Right |
| 👋 Swipe Up | Move Up |
| 👋 Swipe Down | Move Down |
| 🤏 Pinch | Turbo |
| ✊ Fist | Pause |
| ✋ Open Palm | Restart |
